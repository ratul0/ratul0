#### 🧰 Agent skills I use to ship them

Building these products, I turned the parts I kept repeating into agent skills. They work in Claude Code, Cursor, Codex and any agent that reads `SKILL.md`.

| Skill | What it does |
|---|---|
| [shopify-app-idea-validator](https://github.com/ratul0/shopify-app-idea-validator) | Checks a Shopify app idea against market demand, competitors and earning potential before you build it |
| [shopify-app-factory](https://github.com/ratul0/shopify-app-factory) | Builds a production-ready Shopify app from idea to deployment |
| [shopify-app-release-assistant](https://github.com/ratul0/shopify-app-release-assistant) | Walks you through every deliverable needed to submit to the Shopify App Store |
| [shopify-app-listing](https://github.com/ratul0/shopify-app-listing) | Writes all 14 App Store listing fields, with compliance checks |
| [shopify-icon-forge](https://github.com/ratul0/shopify-icon-forge) | Designs a Shopify app icon, from concept to PNGs at every required size |
| [ios-app-design](https://github.com/ratul0/ios-app-design) | Designs and reviews SwiftUI screens, onboarding, paywalls and microcopy |
| [depth-writing](https://github.com/ratul0/depth-writing) | Writes and audits persuasive text so it's specific, not generic |
